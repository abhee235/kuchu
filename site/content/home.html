A desk pet for Claude Code

Kuchu sits above your windows and shows what every Claude Code session is doing. It thinks while Claude reads, works while tools run, and asks you when Claude needs a yes.

Get it from the Microsoft Store More ways to install

Free and open source, for Windows 10 and 11, with macOS in preview. Kuchu needs Claude Code, installed separately.

Every session, at a glance

Each Claude Code session gets a card beside the pet: what it is about, and what Claude is doing now, step by step. A ring while a step runs, a check once it is done. When Claude finishes, the card shows the first line of its answer.

With several sessions at work, +N lists the others. Click one and the card follows it. Click the pet for all your sessions, or press Ctrl+Alt+K from anywhere.

How the card works

Say yes from the card

When Claude Code asks to run a command or change a file, the request shows on Kuchu with Allow and Deny. You see the whole command before you allow it; if it is too long for the card, Kuchu offers no Allow and leaves it to Claude Code.

Nothing is allowed without your click. If you don't answer, Claude Code asks in its own window, as it always does.

About permission requests

A life of its own

With no work to show, Kuchu stretches, yawns, looks around, dances, flips its screen or takes a short walk, and naps after a few quiet minutes. It waves hello when you send Claude a message. Drag it and it walks; stroke it with your pointer and it likes it.

It never takes the focus, and clicks go through everywhere but the pet and its cards.

Talk to Claude from Kuchu

Start a conversation in any folder from your sessions list. Kuchu runs your own Claude Code for it, so Claude answers under your own Claude account. Stop it any time, or carry it on in a terminal. About conversations

Yours alone

Kuchu collects nothing and sends nothing anywhere: no account, no analytics, no ads. It installs for your account only, never runs as a service or with administrator rights, and shows you every change to Claude Code's settings before making it. The privacy policy and how it works say exactly what it reads.

Questions

Is Kuchu made by Anthropic?

No. Kuchu is an independent, open-source app that works with Claude Code. It is not made or endorsed by Anthropic.

Can Kuchu allow something without me?

Never. A request is allowed only by your click. If you don't answer, it goes back to Claude Code, which asks in its own window.

Does it slow Claude Code down?

No. Claude Code hands each event to a tiny helper that passes it to Kuchu and exits at once. If Kuchu is not running, the helper does nothing.
