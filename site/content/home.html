Every session at a glance

One card for each session, showing what Claude is doing right now.

A life of its own

With no work to show, it stretches, dances and naps. It waves hello when you send Claude a message. Try it.

Everything else it does

Works in VS Code and any terminal

Every Claude Code session on your computer shows up, wherever you started it.

Several sessions at once

Each has its own card. "+N" lists the others, and a click follows one.

Talk to Claude from Kuchu

Start a conversation in any folder, stop it, or carry it on in a terminal.

Stays out of your way

It never takes the focus, and clicks go through everywhere but the pet and its cards.

Nothing without your click

An unanswered request goes back to Claude Code. A timeout never allows anything.

Collects nothing

No account and no analytics. Open source, and no administrator rights needed.

Set it up in three steps

  1. Install Kuchu

    From the Microsoft Store, or from GitHub for Windows and macOS.

  2. Click Connect

    Kuchu shows the change to Claude Code's settings first, and keeps a copy.

  3. Use Claude Code as usual

    Every session in VS Code or a terminal shows up beside the pet.
