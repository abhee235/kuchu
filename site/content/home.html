Put Kuchu on your desk

For Windows 10 and 11, with macOS in preview. Needs Claude Code, installed separately.

Get it from the Microsoft Store

Or say this to Claude Code:

Install Kuchu from https://github.com/abhee235/kuchu

  1. Install Kuchu

    From the Microsoft Store, or from GitHub for Windows and macOS.

  2. Click Connect

    Kuchu shows the change to Claude Code's settings first, and keeps a copy.

  3. Use Claude Code as usual

    Every session in VS Code or a terminal shows up beside the pet.
