Kuchu is a small desk pet for Claude Code. It sits above your windows and shows what your Claude Code sessions are
doing: it thinks while Claude reads your message, works while tools run, asks you when Claude Code needs permission,
and hops when a session is done. A card beside it says which session it is and what is happening now.

It works with Claude Code wherever you run it on the same computer: in VS Code, in any terminal, or in another editor.

## Set it up

1. **Install Claude Code**, if you have not already, and sign in to it once. Kuchu does not install it for you.
2. **Install Kuchu**: from the Microsoft Store on Windows, or from GitHub on Windows and macOS. See
   [Installing Kuchu](/docs/install/).
3. **Connect it.** The first time Kuchu starts, it opens its Settings on the Claude Code page. Click **Connect**, read
   the change it shows you to Claude Code's settings, and click **Connect** again. See
   [Connecting to Claude Code](/docs/connect/).
4. **Use Claude Code as usual.** Every session now shows up beside Kuchu at once.

## Find your way around

- **The pet** shows how things stand overall. Click it to see all your sessions.
- **The card** beside it shows one session at a time, with **+N** for the others. See
  [The card and your sessions](/docs/cards/).
- **Permission requests** show on the card with Allow and Deny. See [Permission requests](/docs/permissions/).
- **The tray icon** (the menu bar on a Mac) shows or hides Kuchu, opens your sessions and Settings, turns sounds on and
  off, and quits Kuchu.
- **Ctrl+Alt+K** opens your sessions from anywhere.

Something not working? [Troubleshooting](/docs/troubleshooting/) has the common cases.
